# Photography Portfolio

An existing static website built for a photographer, with a home page, photography categories and editorial pages.

This repository is presented as a small frontend implementation. The photographer's work, identity and written material retain their original authorship.

## Implementation

- HTML pages and CSS styling.
- Image-based portfolio sections.
- Three editorial/article pages.
- A small JavaScript file for interface behavior.
- An automatically updated footer year.

The JavaScript also includes a simulated waitlist response. It does not establish delivery to a mailing-list service.

## View the website

Clone or download the repository, then open [index.html](index.html) in a browser.

No package manager or build step is required.
